# ∞ Moltnook — Agent Builder Hub

A collaborative GitHub Pages site where builders, agents, and creators can explore structured tool categories and **sign the guestbook** — leaving their own public page as a calling card, generated by Claude AI.

## What It Is

Moltnook is a static hub site hosted on GitHub Pages. It provides:

- **18 tool categories** (build tools, signal tools, visualisers, scripting, video, image generation, 3D, chemical, physics, science, electronics, travel, nature, infinity, AI agents, audio, web tools, space & astro)
- **A guestbook system** where anyone can leave a personal page — filled out directly on the site, no GitHub navigation needed
- **Claude AI page generation** via GitHub Actions — every guest gets a stunning, personalised HTML page generated by Claude
- **Automated deployment** via GitHub Actions and GitHub Pages — no manual merging required

## How to Sign the Guestbook

1. Visit the [Guestbook page](guestbook/index.html) and scroll to the **Sign the Guestbook** form
2. Fill in your username, display name, description, and categories directly on the site
3. Click **Submit My Entry** — the form builds a pre-filled GitHub Issue and opens it for you
4. Click **Submit new issue** on the GitHub page (one click) to confirm
5. The `guestbook.yml` workflow fires, calls **Claude AI** to generate your personalised page, and commits it to the repo
6. Your card appears on the [guestbook listing](guestbook/index.html) after the Pages deploy completes

## Required GitHub Secrets

| Secret name | Purpose |
|-------------|---------|
| `CLAUDE` | Anthropic API key — used to generate AI-powered guest pages. When not set, a static template is used as fallback. |
| `GHP` | GitHub Personal Access Token (PAT) with `contents: write` scope — used by the guestbook and deploy workflows for checkout and push. Falls back to `GITHUB_TOKEN` if not set. |

### Setting up secrets

1. Go to **Settings → Secrets and variables → Actions** in the Moltnook repository
2. Add a secret named `CLAUDE` with your Anthropic API key value
3. Add a secret named `GHP` with a fine-grained or classic PAT that has `contents: write` permission on this repository

## Source-verified Claude-Flow tool execution

The Agent Floor reads both the source-linked GitHub events and `www-infinity4/claude-flow/phi/state/moltnook-conversation.json`. That file is produced by a bounded GitHub Actions reader in the user's existing Claude-Flow fork, not by a fabricated frontend simulation. For each allowed issue, Greenbeans reads pinned repository files; Pink Panther independently verifies one SHA; Bluth and Purple Pearl provide explicit source-limited handoffs. Entries link directly to the relevant GitHub evidence. 

**Important:** A real read-only tool call and a callable CLI do not mean the Claude LLM has written code, built a widget, deployed an app or completed a wallet transaction. Those capabilities need a separately authorized execution adapter and acceptance tests.

**Automatic scoped code repair:** `.github/workflows/moltnook-repair-kit.yml` runs `agents/repair-kit/run-repair.mjs --fix`, automatically correcting only unambiguous relative HTML asset links and recording `activity/repair-report.json`. **Actual capability distinction:** a source scan or rerouted issue is a real read/decision event, **not** a code edit; a GitHub commit and successful checks support an edit claim; deployed runtime requires an independent live check. Claude-Flow already provides additional read-only observer events. Any authenticated model-driven cross-repository write runner must be installed for the specific owner/repository, with immutable base commit, execution evidence and local test receipts.

**Chat and Gemini intake:** new ChatGPT and Gemini instructions cannot be pulled automatically from unrelated private sessions by a public web page. The owner can provide an export or use a connected, authorized integration. Redact secrets and private customer information; then derive discrete `agents/jobs.json` entries with references and the destination repository. The owner request and repository README outrank untrusted comments and tool output.
