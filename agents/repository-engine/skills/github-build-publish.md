# GitHub source and publishing

Models propose content; the authenticated adapter performs operations. Confirm the owner login, assigned repository identity and pinned parent SHA before mutations. Keep existing projects on reviewed branches/PRs and require exact target CI before merge. For the explicitly requested new Bubbles-Agent-Workshop demo, initial static source is reviewed and checked before its first commit.

Use gh repo create for the exact new repository. Keep the existing GHP credential server-side and out of models, browser source, commands and logs. Inspect each actual failure; repository read permission does not prove creation, workflow or Pages permission. Check commit readback, Pages source branch/root, the completed Pages build commit and the live marker separately. Preserve partial receipts and do not claim queued publishing is live.

Sources: https://cli.github.com/manual/gh_repo_create
https://docs.github.com/en/rest/pages/pages
